How the research tool works

It studies patterns rather than copying listings.

  1. SearchPulls public, active listings for a keyword through the official marketplace API.
  2. AnalyzeDescribes each listing's style in general terms: typography, palette, wording structure, photo layout.
  3. SummarizeRanks listings by public demand signals and rolls the findings into a single market report.
  4. BriefProduces direction for original designs, plus a list of trademarks and phrases to avoid.

Data use

How the research tool handles marketplace data.

  • Read-only. It does not post, edit, message or buy anything.
  • Public data only. It uses public listing information. It does not access buyer accounts, orders or personal data.
  • Official API only. No scraping, and requests stay within published rate limits.
  • Internal use. Results are used for the studio's own research and are not sold or shared.
  • Short retention. Raw listing data is kept only as long as needed for a report and is refreshed from the API rather than stored long-term.
